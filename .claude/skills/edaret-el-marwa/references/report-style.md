# أسلوب تقارير سولفكس — House style & pipeline

## القاعدة الذهبية
**كل مُخرَج = PDF + Excel** (حيث يوجد جدول)، بأسلوب سولفكس، بأسماء ملفات عربية،
**كل بند/قسم في صفحة جديدة**، بدون كلمة «سري». المانيوالات بالعربية الفصحى
(المحادثة ممكن تفضل عامية). لا تترجم معرّفات النظام (أكواد الحسابات، أسماء الفروع،
أرقام الحركات) — تبقى كما هي للتتبّع.

## التصميم (skill `anthropic-skills:solvex-ar-a4`)
- كحلي `#15294d` + ذهبي `#cfa152`، خط واحد **IBM Plex Sans Arabic** (400/600/700).
- A4، RTL، letterhead بالشعار، صفحة غلاف، فهرس، ثم الأقسام.
- فاصل الصفحات: `.page.step{page-break-before:always}`.
- جداول: `table-layout:fixed` + `<colgroup>` تجمع 100% (العمود النصّي أعرض).
- الأرقام والأكواد: `direction:ltr` داخل خلايا عربية؛ أرقام كاملة بلا «…».
- أصول التصميم في:
  `/root/.claude/skills/synced/<org>_<id>/solvex-ar-a4/assets/`
  (`report.css`, `fonts/plex_*.woff2`, `logo_b64.txt`).

## خط الإنتاج (HTML → PDF)
1. ابنِ HTML واحد مضمّن الخطوط (base64 `@font-face`) + كل `report.css` inline + الشعار data-URI.
2. ارسمه: `python3 render_nosecret.py <abs_input.html> <abs_output.pdf> "SLX-IA-2026-XXX"`
   - استخدم **مسارات مطلقة** (render يفشل مع النسبي: `ERR_INVALID_URL`).
   - الـ footer يرسمه الراسم: معرّف التقرير · رقم الصفحة · «Solvex Internal Audit» (بدون «سري»).
3. **راجِع بالعين:** `pdftoppm -png -r 90 -f N -l N out.pdf pg` ثم اقرأ الصورة —
   خصوصًا حواف الجداول والعناوين قرب نهاية الصفحة.

## Excel (openpyxl)
- `ws.sheet_view.rightToLeft = True`؛ `ws.auto_filter.ref = "A1:..."`؛ `freeze_panes="A2"`.
- الألوان hex من 6 خانات (`"555555"` لا `"555"`) وإلا «Colors must be aRGB hex».
- رأس كحلي أبيض عريض، تلوين صفوف بالتناوب، شيت ملخّص + شيت تفصيلي لكل محور.
- اعرض المبالغ الصغيرة بدقّة `:,.2f` (قيمة 0.03 تظهر «0» مع `:,.0f` — خطأ).

## بنية التقرير المعتادة
الغلاف → **الفهرس في صفحة مستقلة** (أقسام + أرقام دائرية + نقاط ربط) → التقرير
(خلاصة تنفيذية بـ KPIs + تحليل + توصيات بالأولوية) → **صفحة فاصلة «الملاحق»** →
الملاحق التفصيلية (سطر بسطر، قابلة للفلترة في Excel).

## قاعدة اللغة
- تقارير/مانيوال للموظفين: **فصحى**.
- العناوين «أولًا/ثانيًا/…»، صناديق: `.plain` (شرح)، `.warn` (تحذير/تصحيح)،
  `.impact` (أثر)، `.note`/`.note.ok` (طمأنة). رقائق الخطورة: حرجة `#c0392b`،
  متوسطة `#b8860b`، منخفضة `#2e7d32`.
